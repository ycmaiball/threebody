## 路线 A：零安装部署（推荐）

全程在浏览器完成，**不需要在这台电脑上安装任何东西**。

### 第 1 步：在 GitHub 创建仓库

1. 打开 <https://github.com/new>（需先登录 GitHub 账号）
2. 填写：
   - **Repository name**：`three-body-site`
   - **Description**：`《三体》三部曲沉浸式设定集网站`
   - **Public / Private**：随意，Public 便于 Vercel 免费部署
3. ⚠️ **不要勾选** "Add a README file"、"Add .gitignore"、"Choose a license"
   （保持空仓库，否则稍后上传会冲突）
4. 点击 **Create repository**

### 第 2 步：上传文件

在新建好的仓库页面：

1. 点击 **uploading an existing file**（或 `Add file` → `Upload files`）
2. 把 `three-body-site` 文件夹里的**全部内容**拖进去：

   ```
   index.html    404.html    README.md    部署手册.md
   package.json  vercel.json .gitignore   dev-server.js
   css/          js/         tools/
   ```

   > 直接把文件夹拖进浏览器即可，子目录会自动保留结构。
   > **不要**上传 `node_modules`、`_shots`、`_preview`（.gitignore 已排除，且用不到）。

3. 下方 **Commit changes** 填写：`feat: 三体沉浸式设定集网站`
4. 点击 **Commit changes**

✅ GitHub 部分完成，仓库地址形如 `https://github.com/<你的用户名>/three-body-site`

### 第 3 步：部署到 Vercel

1. 打开 <https://vercel.com/signup>，选择 **Continue with GitHub** 登录并授权
2. 进入 <https://vercel.com/new>
3. 在 **Import Git Repository** 列表中找到 `three-body-site`，点击 **Import**
4. 配置页**保持默认即可**：

   | 配置项 | 值 |
   | --- | --- |
   | Framework Preset | `Other` |
   | Root Directory | `./` |
   | Build Command | **留空** |
   | Output Directory | **留空** |
   | Install Command | **留空** |

   > 本项目是纯静态站点，**没有构建步骤**，留空即可正常工作。
   > `vercel.json` 已配置好安全响应头与静态资源缓存策略，无需额外设置。

5. 点击 **Deploy**，等待约 10–20 秒

### 第 4 步：获取线上地址

部署成功后，Vercel 会给出：

- **生产地址**：`https://three-body-site-<随机串>.vercel.app`
- 之后每次向 GitHub 推送代码，Vercel 会**自动重新部署**

需要绑定自定义域名：项目 → **Settings** → **Domains** → 输入域名并按提示配置 DNS。

## 路线 B：命令行部署（需先安装 git）

如果你希望用命令行管理版本，先安装 git。

### 第 1 步：安装 git

**方式一：官网下载（推荐）**

1. 打开 <https://git-scm.com/download/win>
2. 下载 64-bit 安装包并运行，**一路默认下一步**即可
3. 安装完成后**关闭并重新打开**终端，验证：

   ```powershell
   git --version
   ```

**方式二：winget（若系统可用）**

```powershell
winget install --id Git.Git -e --source winget
```

### 第 2 步：配置身份

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"
```

### 第 3 步：初始化并提交

在项目目录（`three-body-site`）下执行：

```powershell
git init
git add .
git commit -m "feat: 三体沉浸式设定集网站"
git branch -M main
```

### 第 4 步：关联远程仓库并推送

先在 <https://github.com/new> 创建一个**空仓库**（同路线 A 第 1 步），然后：

```powershell
git remote add origin https://github.com/<你的用户名>/three-body-site.git
git push -u origin main
```

首次推送会弹出浏览器要求登录 GitHub 授权，按提示完成即可。

> **提示**：如果推送时报 `remote: Support for password authentication was removed`，
> 说明 GitHub 已停用密码推送。请改用
> [Personal Access Token](https://github.com/settings/tokens)（勾选 `repo` 权限）
> 作为密码，或安装 [GitHub CLI](https://cli.github.com/) 后执行 `gh auth login`。

### 第 5 步：Vercel 部署

同路线 A 第 3 步（网页导入），或使用 CLI：

```powershell
npm i -g vercel
vercel          # 首次会引导登录
vercel --prod   # 发布到生产环境
```

## 常见问题排查

### ❌ Vercel 部署后页面空白

**原因**：访问了错误的路径，或文件未完整上传。

**排查**：

1. 确认仓库根目录**直接**包含 `index.html`（而不是嵌套在 `three-body-site/index.html`）
   —— 这是最常见的问题。若嵌套了，在 Vercel 项目设置里把
   **Root Directory** 改成 `three-body-site` 即可。
2. 打开浏览器控制台（F12）查看是否有 404 资源错误。

### ❌ 页面样式丢失 / 无星空

**原因**：`css/` 或 `js/` 目录未上传成功。

**排查**：访问 `https://你的域名/css/style.css`，若返回 404 说明目录缺失，请补传。

### ❌ GitHub 上传时提示文件冲突

**原因**：创建仓库时勾选了 "Add a README file"。

**解决**：删除仓库重建（不勾选任何初始化选项），或先 `git pull --rebase` 再推送。

### ❌ 中文文件名（部署手册.md）乱码

**解决**：Git 默认配置即可正常处理 UTF-8 文件名。若出现乱码，执行：

```powershell
git config --global core.quotepath false
```

### ✅ 部署前自检

在本地项目目录执行验证脚本，确认一切正常再部署：

```powershell
node tools/verify.js
```

脚本会启动无头浏览器，检查控制台错误、内容渲染、横向溢出与全部交互功能。
